반응형 & 웹 전달 가이드

현재 Verba 시안을 PC 1440+ / Tablet 768+ / Mobile 390 3단계로 리플로우되게 구현했어요. 아래 프레임은 각자 제 폭에 맞춰 실제로 반응합니다(컨테이너 쿼리). 웹 전달 시 주의사항도 함께 정리했습니다.

웹 전달 주의사항

1브레이크포인트

Mobile ≤767 · Tablet 768–1023 · Desktop ≥1024. 그 사이는 유동(fluid). 데스크톱은 콘텐츠 max-width로 과확장 방지(1440+에서도 레이아웃 동일, 여백만 넓어짐).

2내비게이션

Desktop 사이드바 → Tablet 아이콘 레일(64px) → Mobile 하단 탭바 + 상단 햄버거. 데스크톱 nav가 그대로 모바일에 들어가지 않게.

3그리드 축소

액션 카드 4→2→1(또는 2), 대시보드 패널 1.6/1 → 1열. 결과 채널 카드는 항상 세로 스택.

4터치 & 호버

모바일 터치 타깃 ≥44px. hover는 데스크톱 전용(모바일은 active/focus). @media (hover:hover)로 분리.

5폰트

Pretendard 웹폰트 로드(SIL OFL) + 시스템 폴백. 한글 잘림·자간 확인. 무게는 라이트(700/600/400).

6가로 스크롤 금지

표·긴 카피는 컨테이너 내부에서만 overflow-x:auto. 긴 텍스트 말줄임(ellipsis). 바디는 절대 가로 스크롤 X.

7뷰포트 단위

모바일 주소창 때문에 100vh 대신 100dvh. 하단 고정 탭바는 safe-area-inset 고려.

8접근성

대비 AA(무게 낮춘 뒤 재확인), 포커스 링, 키보드 내비, prefers-reduced-motion 대응.
